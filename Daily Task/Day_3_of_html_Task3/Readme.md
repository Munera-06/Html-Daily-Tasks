# Day 3 – HTML Task 3: RCB

## 📌 Project Overview

This is my **Day 3 HTML Task**, created using basic HTML tags and elements.

The webpage is based on **Royal Challengers Bengaluru (RCB)**, a popular cricket team in the Indian Premier League (IPL). The webpage presents information about the team, its players, achievements, and other important details.

* Text Formatting Tags

* Lists
