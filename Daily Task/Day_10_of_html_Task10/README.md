# Day 10 - HTML Task: Personal Portfolio Website

## Task
Create a personal portfolio website using HTML and CSS. The page introduces a developer, displays skills and projects, and provides contact information.

## Sections
- Home
- About Me
- My Skills
- My Projects
- Contact Me
- Footer

## Files
```text
Day_10_HTML_Task/
├── index.html
├── style.css
└── README.md
```

## Concepts Practiced
- HTML semantic elements: `header`, `nav`, `main`, `section`, `article`, `footer`
- Headings, paragraphs, links, and lists
- CSS selectors and box model
- Flexbox and hover effects
- Responsive design with a media query
- Smooth scrolling

## How to Run
1. Download or clone this folder.
2. Open `index.html` in a web browser.
3. Edit the sample name, skills, projects, and contact details with your own information.

## Technologies
- HTML5
- CSS3
