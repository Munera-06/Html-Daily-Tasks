# Day 9 of HTML Task 9 – Eco Travel Guide

## Project Overview

This project is a single-page **Eco Travel Guide** website created using **HTML5 only**. The page provides information about eco-friendly travel, sustainable tourism, popular destinations, travel activities, useful travel tips and the benefits of responsible tourism.

## Technologies Used

* HTML5
* HTML Semantic Tags

## Sections Included

* Header and Navigation
* Discover Responsible Travel
* What Is Eco Travel?
* Beautiful Eco Destinations
* Eco-Friendly Travel Activities
* Sustainable Travel Tips
* Benefits of Eco Tourism
* Smart Travel Packing
* Start Your Eco Journey
* Footer and Contact Information

## HTML Concepts Used

* Basic HTML5 Structure
* Headings and Paragraphs
* Navigation Links
* Images
* Semantic Tags
* Sections and Articles
* Ordered and Unordered Lists
* Description List
* Blockquote
* Address Tag
* Internal Page Links
* Footer

## Features

* Simple and clean single-page structure
* Eco travel themed content
* Multiple travel destination images
* Internal navigation links
* Informative travel tips
* Sustainable tourism information
* HTML-only implementation without CSS or JavaScript

## Learning Outcome

Through this task, I practiced creating a complete webpage using HTML5 semantic elements and learned how to organize content into multiple sections. I also practiced working with images, links, lists, articles and different HTML elements to create a meaningful webpage.
