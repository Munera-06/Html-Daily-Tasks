# Day 8 – HTML Task 8: Urban Coffee

## 📌 Project Overview

This is my **Day 8 HTML Task**, created using HTML5 and different HTML elements.

The webpage is based on **Urban Coffee**, a modern coffee shop-themed webpage designed to present coffee, beverages, food items, and café-related information in a simple and organized way.
